Bass Shakers

Bass Shakers convert telemetry into low-frequency audio for tactile feedback.

Use them to feel:

  • engine RPM
  • road texture
  • suspension hits
  • tyre slip
  • brake lock
  • gear shifts

Input Source​

DashForge can drive Bass Shakers from telemetry, audio input, or both.

SourceBest forNotes
Telemetryprecise RPM, tyre slip, brake lock, suspension and gear shiftsRecommended for supported games.
Audio Inputgames without telemetry, console audio, ambient sound, or virtual audio devicesDetects bass energy and sharp transients from the selected system input.
Telemetry + Audioadding extra rumble and impact peaks on top of telemetryKeep audio gain moderate to avoid masking telemetry detail.

When audio mode is enabled, choose Audio Input Device in the Bass Shakers panel. System Default follows the macOS default input. You can also choose a specific microphone, line input, capture card, or virtual input such as BlackHole, Loopback, or another audio routing tool.

DashForge does not capture protected system audio by itself. To react to game audio, route the game or system output into a virtual input and select that device in Audio Input Device.

Audio Input Tuning​

The audio mode exposes two meters:

  • Input: overall incoming level
  • Events: detected bass/transient events that can trigger stronger shaker hits

Useful starting values:

SettingStartPurpose
Audio Gain55-70%Overall amount of audio-driven vibration.
Sensitivity60-85%How easily peaks become events.
Noise Gate3-7%Ignores fans, room noise and quiet idle audio.
Bass Mix65-85%Low-frequency rumble contribution.
Transient Mix45-75%Sharp impacts, gear thumps and hit detection.

Raise Noise Gate until the shaker is quiet when the room/game is quiet. Then raise Sensitivity until real events show on the Events meter.

Basic Setup​

  1. Open Settings > Hardware.
  2. Enable Bass Shakers.
  3. Choose Telemetry or Audio Input.
  4. If using audio mode, choose Audio Input Device.
  5. Choose a default audio output.
  6. Add one shaker.
  7. Select its cockpit position.
  8. Choose output device and channel routing.
  9. Start with moderate gains.

For a complete example using a Nobsound USB amplifier and a Douk Audio BS-1 50W bass shaker, follow Tutorial: Nobsound + Douk Audio BS-1 50W.

Recommended first shaker:

SettingValue
PositionSeat Center
Engine RPM40-50%
Road35-45%
Suspension30-45%
Slip20-35%
Brake Lock10-20%
Gear Shift35-50%

Cockpit Positions​

DashForge supports:

PositionTypical mounting
Seat Left / Seat Center / Seat RightUnder or behind the seat
Rear Left / Rear Center / Rear RightRear frame, rear deck, or rear chassis bar
PedalsGeneral pedal plate vibration
Brake PedalBrake-specific feedback
Clutch PedalClutch-specific feedback
Accelerator PedalThrottle-side pedal vibration
Wheel DeckSteering wheel or dashboard frame
CenterSingle-shaker fallback or chassis center

The cockpit map shows where each shaker is assigned and lights up as telemetry drives it. Position affects the signal mix: rear placements emphasize rear slip and rear suspension, pedal placements emphasize brake lock and pedal events, and seat/center placements work well for engine and road rumble.

Output Routing​

Each shaker can use:

  • the default audio device
  • a specific audio output
  • a single stereo channel
  • L+R Mono when you want the same shaker signal on both left and right channels

Use L+R Mono only when the two physical outputs should receive the exact same signal. For independent left/right shakers, keep separate channels.

Important Parameters​

SettingMeaning
Input SourceTelemetry, Audio Input, or both.
Default OutputFallback sound card for shakers without a specific row output.
MasterGlobal output level for all shakers.
UpdateControl update rate. 60 Hz is a good default.
RPM RangeMaps engine RPM to low-frequency tone range.
Idle CutoffSilences engine vibration below the chosen RPM.
GainPer-shaker volume trim.
Channel / Output ModeSends the shaker to left, right, or L+R mono output.
Effect MixPer-shaker blend of engine, road, suspension, slip, brake lock, and gear shift.

Tuning Advice​

  • Tune one effect at a time.
  • Lower engine if it masks road and suspension detail.
  • Keep brake lock sharp but not constant.
  • Use separate outputs only after the basic setup feels right.
  • Watch the performance panel during long sessions.
