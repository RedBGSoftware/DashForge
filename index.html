02 · NETWORK

Secure local sharing

Discover nearby DashForge apps, review every incoming request before transfer, and share dashboards, recordings, or sessions with linked files.

Background library refresh, parser-aware replay, configurable UI rate, and an optional performance overlay help keep live and replay workflows observable.

One cockpit, more ways to connect

DashForge ships with focused companion tools for Windows integrations and repeatable development tests.

DashForge Bridge

A portable Windows companion for Assetto Corsa shared memory and dashboard-triggered keyboard, Win32, or mouse commands.

DashForge Lab

An internal macOS simulator for generated game telemetry, `.dfrec` replay, hardware receivers, and a keyboard, mouse, or gamepad-driven 3D vehicle.
