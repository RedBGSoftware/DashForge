DashForge Documentation

Welcome to the official DashForge user documentation.

DashForge is a telemetry cockpit for racing games: live UDP dashboards, recordings, replay, session analysis, local sharing, hardware output, Bass Shakers, Wind Simulator, Bridge commands, Stream Deck, Web Builder, Lab, and AI control.
