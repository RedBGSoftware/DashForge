Widget Reference

DashForge widgets are the building blocks of a dashboard page. Each widget reads the normalized telemetry model, so the same layout can work with live UDP, recordings, replay, and supported custom profiles.

This page mirrors the widget list implemented in DashForge 1.1.0. If a value shows 0, --, or stays empty, open Data and check whether the selected game or profile exposes the required telemetry field.

Fuel Status​

Use Fuel Status when the profile exposes fuel, fuel-in-tank, fuel capacity, or fuel-lap fields. The widget can be shown as a full card, minimal readout, horizontal bar, or vertical bar depending on available space.

Battery Status​

Use Battery Status for F1 ERS, EV battery, hybrid energy store, or any mapped energy field. The compact modes are useful on small pages where the full card is too visually heavy.

Input Widgets​

WidgetPreviewAccessDefault sizeBest for
InputsStandard12x3Throttle, brake, handbrake, clutch, and steering visualization.

Use Inputs while testing hardware, tuning pedal discipline, or checking parser normalization. It is also a good debug widget when telemetry appears inverted or clamped.

Timing Widgets​

WidgetPreviewAccessDefault sizeBest for
Circuit InfoStandard4x2Lap number, race position, current/last/best timing summary.
Lap DeltaStandard4x3Delta, trend, and lap timing hints during live or replay driving.

Circuit Info is usually a first-page widget. Lap Delta fits better on a race or analysis page where timing context matters more than raw speed.

Race Control​

Race Control is the fastest way to build a readable first dashboard page. It combines speed, RPM, gear, and inputs in one large card.

Analog Race Control​

Analog Race Control is the most customizable speed/RPM widget. It supports speed-only, RPM-only, or dual display; dial shapes; needle styles; tick density; redline band visibility; digital value placement; colors; and transparent or styled dial backgrounds.

Tyre And Grip Widgets​

WidgetPreviewAccessDefault sizeBest for
TyresStandard12x3Tyre temperatures, slip, pressure, and basic tyre state.
Drift Tyre HUDPremium5x5Drift angle, rear tyre stress, and grip status.
Grip WindowPremium5x4Tyre temperature, slip, and grip confidence.

Use these widgets only when the game exposes enough tyre data. Some titles expose temperature but not detailed slip or pressure; in that case the widget still loads, but some fields may stay empty.

Dynamics Widgets​

Motion StatsStandard12x3Raw motion, G-force, yaw, pitch, and roll diagnostics.

Dynamics widgets are useful for driving analysis, setup testing, and replay review. They are more sensitive to noisy parser data than basic speed or gear widgets, so verify motion fields in Data if they look wrong.

Live Trace​

Live Trace uses the same analysis engine as sessions. It tracks path samples, events, and detail cards while the widget is visible. For performance, keep this on analysis pages or only one active page at a time.

Coaching Widgets​

The coaching widgets are opinionated helpers. They are best used after confirming that speed, brake, throttle, tyre, and motion fields are mapped correctly for the selected game.

Data Widgets​

WidgetPreviewAccessDefault sizeBest for
Telemetry TileStandard3x1Compact tile for any mapped telemetry value.

Telemetry Tile is the fastest way to debug or expose one specific field. Use it for custom game profiles, hardware testing, or niche values that do not need a dedicated widget.

Controls Widgets​

WidgetPreviewAccessDefault sizeBest for
Action ButtonStandard3x1Triggering DashForge actions, Bridge commands, or game controls.

Action Button can start recording, save the live buffer, toggle UDP, or send a Bridge command. Bridge commands can simulate keyboard, mouse, Win32, or gamepad style inputs through DashForge Bridge.

Action Button also supports button-box skins:

  • Capsule
  • Push Button
  • On / Off
  • Start Engine
  • Rocker
  • Toggle Lever

Use skin colors and label placement to build readable control panels. Toggle skins keep a local visual state for Bridge commands, but they do not confirm the real state of the game.

Media Widgets​

WidgetPreviewAccessDefault sizeBest for
ImageStandard4x3Imported logos, custom plates, sponsor graphics, or cockpit decoration.
TextStandard4x2Static labels or telemetry-linked text.
StickerStandard2x2Preset stickers, SF Symbols, emoji, or imported image overlays.

Media widgets are useful for dashboard organization. Sticker can use built-in presets, an SF Symbol name, text/emoji, or an imported asset from the dashboard Asset Library. PNG files dropped on the dashboard are imported as Sticker widgets. Keep media light on driving pages and use it more freely on presentation or streaming layouts.

Choosing Widgets For A Page​

For a race page, start with Race Control or Analog Race Control, then add Circuit Info, Fuel Status, Battery Status, and one compact input or shift widget.

For an analysis page, use Live Trace, Telemetry Graph, Multi Trace, tyres, and one or two coaching widgets.

For a hardware or stream page, use Action Button, Telemetry Tile, Inputs, and simple media widgets to label controls.

Performance Tips​

  • Keep high-frequency visual widgets such as Live Trace, Multi Trace, G-Force Radar, and Car Dynamics on separate pages when FPS matters.
  • Prefer compact bar modes for fuel and battery on small displays.
  • Use Telemetry Tile instead of a full widget when you only need one value.
  • Keep decorative Image and Sticker widgets behind telemetry widgets by using a lower z-index when building layered dashboards.
  • If a widget looks wrong, check the field in Data before assuming the widget itself is broken.
