What's New in DashForge 1.1.0

DashForge 1.1.0 expands the app from a live dashboard builder into a complete telemetry workflow for capture, analysis, hardware, and multi-device setups.

Sessions and Driving Analysis​

  • Group multiple recordings into a named session.
  • Add notes, tags, and metadata.
  • Generate a cached track trace and driving analysis.
  • Review braking, lockup, drift, traction, and coaching events.
  • Filter and inspect events directly on the trace.
  • Use the Live Trace widget for the same analysis while driving.

See Sessions and Analysis.

Faster Recordings and Replay​

  • Recording metadata is cached so the Replay and Sessions libraries appear immediately.
  • File scanning refreshes the cache in the background without hiding the current list.
  • Replays select the parser stored in the recording instead of the currently selected live game.
  • Replay progress and controls stay responsive while packets are parsed off the main UI path.
  • .dfrec files can be imported, exported, renamed, annotated, and shared.

Nearby DashForge Sharing​

DashForge instances can discover each other on the local network using Bonjour.

You can send:

  • dashboards (.dfdash)
  • recordings (.dfrec)
  • sessions, including their linked recordings

The receiving device sees the sender, file name, type, and size before any payload is transferred. Data is sent only after the receiver accepts. Imports refresh their library automatically and show transfer progress.

Discovered DashForge devices can also be added directly as UDP forwarder targets. Self-discovery and forwarding loops are filtered.

See Network Discovery and Sharing.

Device Packet Output, Bass Shakers, and Game Control​

  • Send only the telemetry fields required by an ESP32, Arduino, shift light, gear display, or custom controller.
  • Use UDP device packet output for network devices.
  • Use serial output for USB-connected boards.
  • Route bass shakers to dedicated audio outputs, with per-shaker placement, channel, gain, and effect mix.
  • Drive wind simulator fans over UDP or Serial using telemetry-derived fan levels and PWM values.
  • Trigger keyboard, Win32 virtual-key, and mouse actions on a Windows gaming PC through DashForge Bridge.
  • Use the Action Button widget or send the same command packet directly from hardware.
  • Style Action Button widgets as button-box controls with push button, on/off, rocker, start-engine, and realistic toggle lever skins.

See Game Control, Device Packet Output, and Bass Shakers, Wind Simulator, and DashForge Bridge.

More Telemetry and Games​

Built-in parsing now covers:

  • Forza Horizon 6
  • F1 24
  • F1 25
  • Assetto Corsa through DashForge Bridge
  • Assetto Corsa Competizione through DashForge Bridge

The telemetry model now includes wider engine, motion, position, wheel, tyre, suspension, timing, race, weather, and vehicle-status data. Custom JSON game profiles remain supported.

Dashboard Builder​

  • New widgets for live trace, circuit/timing, telemetry tiles, coaching, and actions.
  • Search and functional categories in the widget catalog.
  • Dashboard categories, tags, descriptions, and library filtering.
  • Import/export packages retain dashboard assets.
  • macOS device-size preview buttons for Mac, iPad, and iPhone layouts.
  • Drive Mode hides editing and capture controls; double-click or double-tap exits it.

Diagnostics and Performance​

  • Configurable UI telemetry refresh rate.
  • Optional floating performance panel with FPS, UI update rate, UDP/replay packet rate, CPU, memory, RSS, and network throughput.
  • Runtime cleanup action for bounded caches and logs.
  • Inactive tabs no longer subscribe to high-frequency telemetry updates.
  • Live analysis only runs while a consuming widget is visible.

Companion Tools​

  • DashForge Bridge is available as a portable, single-file Windows executable and as an optional Windows installer with Start Menu shortcuts.
  • DashForge Lab can generate supported game packets, replay .dfrec files, simulate hardware receivers, and drive a generic 3D vehicle using keyboard, mouse, or gamepad input.

See DashForge Bridge and DashForge Lab.
